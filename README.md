# Kayda Intelligence

Private AI Command & Business Operations System.

## V1.1 Operational Foundation

This version introduces:
- A domain model for businesses, contacts, deals, projects, priorities and activities.
- A demo Command Agent service abstraction (`src/lib/command-agent.ts`).
- More intentional operational interactions and detail workspaces.
- A security-updated Next.js foundation.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Architecture direction

Next.js + React + PostgreSQL/Supabase + provider-agnostic AI service layer + GitHub.

The current data is demo-only. No real business credentials or private records are included.
